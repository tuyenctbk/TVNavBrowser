# Google Play Store Feature Screenshots (Android TV)

Standard 16:9 aspect ratio (**1280 × 720** px) screenshots captured directly on Android TV Leanback environment for Google Play Console listing.

| Screenshot | Feature Description |
|---|---|
| [playstore_1_dashboard_dark.png](./playstore_1_dashboard_dark.png) | **OLED Dark Mode Dashboard**: Clean start page with search engine switcher, live clock, category tabs, and TV-friendly portals. |
| [playstore_2_dashboard_light.png](./playstore_2_dashboard_light.png) | **Daylight Adaptive Light Theme**: High-contrast, glare-free light mode with gold focused states and adaptive icons. |
| [playstore_3_web_arcade.png](./playstore_3_web_arcade.png) | **TV Web Arcade & Gaming**: Dedicated gaming portal with Gamepad mode support (D-pad mapped to arrow keys). |
| [playstore_4_free_streaming.png](./playstore_4_free_streaming.png) | **Free TV, Movies & Video Streams**: Quick-launch portals for YouTube, Pluto TV, and Tubi TV with hardware video acceleration. |
| [playstore_5_web_browsing_cursor.png](./playstore_5_web_browsing_cursor.png) | **Full Desktop Web Browsing & Virtual Mouse**: Full-featured web browsing with smooth virtual cursor and quick bookmark bar. |
| [playstore_6_news_knowledge.png](./playstore_6_news_knowledge.png) | **News & Knowledge Portals**: Curated world news sources (BBC News, Reuters, Wikipedia) formatted for living room screens. |
| [playstore_7_bookmarks_manager.png](./playstore_7_bookmarks_manager.png) | **TV Bookmarks Manager**: D-pad friendly bookmarks list with one-touch cloud sync (`Sync Cloud Bookmarks`). |
| [playstore_8_settings_customization.png](./playstore_8_settings_customization.png) | **TV Settings & Customization**: Theme toggles, pointer speed tuning (Slow, Normal, Fast), custom homepage, and ad blocker. |
