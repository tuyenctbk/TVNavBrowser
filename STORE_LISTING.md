### **Full Description** (Max 4000 characters)
Experience the web on your big screen with **NaviTV Browser** — a fast, privacy-focused web browser designed for **Android TV, Google TV, and Smart TV Boxes**.

Whether you are streaming video, reading news from your couch, or exploring websites that weren't designed for television, NaviTV Browser makes navigating the web smooth with your standard TV remote.

**Key Features in v3.2:**

* **AI Page Summary & "Ask This Page" Assistant:** Summarize long articles or ask follow-up questions (*Main Takeaways, Key Facts, Action Steps*) with a 3-Tier AI Engine (Standard Cloud Gemini Flash -> Economy Lite Mode -> Offline On-Device Smart Extractor).
* **Couch Read-Aloud (TTS):** Listen to web articles or AI summaries read aloud using native Android TV Text-to-Speech.
* **Instant "Open on Phone" QR Code:** Scan an on-screen QR code to hand off any web page directly to your smartphone.
* **Smart Link Magnet Virtual Mouse:** Gently slows over nearby clickable buttons and links so selecting web controls with a TV remote is easy. Includes 3 customizable pointer speeds (*Slow / Precise, Normal, Fast*).
* **Web Game Mode & Built-in Offline TV Arcade:** Automatically detects HTML5 canvas games and includes **Neon Runner TV**, a built-in offline D-pad cyber runner game.
* **Built-In Ad & Popup Blocker:** Browse cleaner and faster by blocking intrusive web banners, pop-ups, and trackers.
* **Voice Search & Commands:** Speak into your remote to search the web or trigger hands-free commands (*"Summarize"*, *"Read aloud"*, *"Ask ..."*, *"Dark mode"*).
* **Per-Site Desktop & Text Zoom Memory:** Long-press Desktop Mode to cycle 100% / 125% / 150% / 175% text zoom and remember settings per domain.
